Настройки расширения браузера

Подключитесь к локальному Claude Code Web и задавайте вопросы по выделенному тексту страницы.

1

Запустите claude-web

2

Создайте Token на странице настроек Web

3

Выделите текст и спросите через контекстное меню

Локальное подключение

Расширение подключается только к localhost и не отправляет Token во внешние сервисы.

Не проверено
Как найти каталог расширения при установке через pip?

Откройте страницу настроек Claude Web — там показан каталог расширения и ZIP для скачивания; также можно выполнить в терминале claude-web --extension-path.

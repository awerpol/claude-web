# Журнал изменений

Все важные изменения фиксируются по версиям. Встроенные в приложение разделы What's New и справки используют `static/changelog.json`, а здесь — Markdown-версия для просмотра на GitHub / в Git diff.

Текущая стабильная версия: `2.4.3`.

## v2.4.3 - 2026-09-27

- **FIX** Новая сессия проекта отправляется повторно после завершения разбора первого сообщения, больше не создаётся ошибочно новая сессия, корректно переиспользуется текущая сессия

## v2.4.2 - 2026-09-19

- **FIX** Windows: в вызовах subprocess явно указана кодировка UTF-8, исправлено падение декодирования GBK в китайской системе (Issue #12)
- **FIX** Windows: после импорта сессии CLI отправка сообщения давала NotADirectoryError; реальный cwd определяется по файлу JSONL и записывается в базу (Issue #11)
- **FIX** Большие файлы (>200k символов) теперь передаются ссылкой на путь, а не встроенно, во избежание лимита тела запроса API 32MB
- **FIX** После выбора `@`-агента в поле ввода показывается только компактный маркер, а полный текст-подсказка Task разворачивается при отправке, чтобы поле ввода не растягивалось
- **FIX** При перетаскивании файлов приоритет отдаётся абсолютному пути; если путь не удаётся найти, подсказка стала дружелюбнее и содержит рекомендации
- **FIX** Событие `session_auto_recovered` считается успешным, очередь восстановленных сообщений продолжает отправку, исправлена проблема холостого хода

## v2.4.1 - 2026-09-05

- **FEATURE** В рабочем режиме в подсказках `@` добавлена категория «Агенты»: переиспользует шаблоны Agent, после выбора вставляется текст-подсказка, чтобы модель через Task запустила соответствующего субагента (только рабочий режим, режим чата не затронут)
- **IMPROVE** В задачах по расписанию «ID привязанной сессии» заменён ручной ввод на выбор сессии из выпадающего списка (показывается заголовок + значок режима); если сессия удалена, прежнее значение сохраняется без молчаливой потери
- **TEST** Все 337 тестов проходят; проверена парность i18n между китайским и английским
